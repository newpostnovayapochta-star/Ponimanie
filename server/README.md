# Понима API

Минимальный серверный шлюз для диалога приложения «Понима» с моделью, совместимой с форматом OpenAI Chat Completions.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm start
```

Переменные окружения:

- `OPENAI_API_KEY` — обязательный секретный ключ. Хранить только в настройках окружения хостинга, никогда не добавлять в Android-приложение или Git.
- `OPENAI_MODEL` — модель; по умолчанию `gpt-4o-mini`.
- `OPENAI_BASE_URL` — адрес совместимого API; по умолчанию OpenAI Chat Completions.
- `PORT` — порт сервера; по умолчанию `8787`.

## Проверка

`GET /health` возвращает состояние сервиса.

`POST /chat` принимает JSON:

```json
{
  "messages": [
    { "role": "user", "content": "Что такое понимание?" }
  ]
}
```

Успешный ответ:

```json
{ "reply": "..." }
```

## Важные ограничения перед публичным запуском

Это стартовый серверный каркас, а не уже размещённый в интернете сервис. Перед подключением Android-клиента нужно развернуть его на выбранном хостинге, задать секрет `OPENAI_API_KEY`, настроить HTTPS, ограничения частоты запросов, лимиты расходов и политику хранения логов. Не отправляйте реальные пользовательские сообщения на сервер до ясного уведомления пользователя и проверки политики обработки данных.

В сервере нет постоянного хранения переписки. Сообщения передаются провайдеру модели только при вызове `POST /chat`.
